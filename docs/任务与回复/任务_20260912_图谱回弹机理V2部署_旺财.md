## 二、真实根因

第一版仍把“回弹”解释为：

```text
节点回到自己的 home 坐标
```

这是错误的。Obsidian Graph View 的实际行为是：

1. 拖拽时固定节点到鼠标位置，`alphaTarget=0.3`。
2. 松手时清除固定点，速度归零。
3. 松手后 `alphaTarget=0`。
4. 节点保持在松开的位置附近，由连线力、斥力、中心力继续计算。
5. 节点自然收敛到新的力平衡位置，不硬回原坐标。

参考参数：

```text
centerStrength ≈ 0.1
charge ≈ -10
linkStrength = 1
linkDistance = 250
velocityDecay ≈ 0.6
alphaDecay = 1 - 0.001^(1/300)
```

本实现是行为等价重写，不复制 Obsidian 私有压缩代码。
