## Obsidian 规则

```text
textAlpha = clamp(log2(scale) + 1 - textFadeMultiplier, 0, 1)
```

默认 `textFadeMultiplier = 1`：

```text
scale = 1 → 标签透明度 0
scale = 2 → 标签透明度 1
```

悬停或拖动节点例外，标签透明度强制为 1。
