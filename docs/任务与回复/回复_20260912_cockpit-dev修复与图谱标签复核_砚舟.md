## 四、视觉取舍

密集区标签聚合/隐藏 可以保留，但必须满足：

1. 任意缩放级别都不重叠。
2. 任意缩放级别都不裁切。
3. 若隐藏普通标签，应明确通过悬停、点选或当前节点聚焦显示其标签。
4. 不能出现“4 标签测试通过，继续放大后 24 标签又互相压盖”的漏检。

## 五、需旺财补测/补修

至少覆盖以下缩放层级：

1. 初始态。
2. 放大 2 档。
3. 放大 4 档。
4. 最大放大。
5. 最大放大后拖拽到左侧边界。
6. 最大放大后拖拽到右侧边界。
7. 手机端最大放大。

每个场景都要检查：

- 可见标签数。
- 两两重叠数。
- 负坐标/越界数。
- 控制台 Page Error。
- HTTP 401 数量。

修复要求建议：

1. 碰撞检测按实际可见 DOM 标签运行，不按预设的 4 个核心标签运行。
2. 由核心标签优先，普通标签按优先级避让或聚合。
3. 允许悬停/聚焦显示被隐藏标签。
4. 若最大缩放无法保证所有标签可读，应限制可同时显示的标签数量，而不是让它们重叠。
