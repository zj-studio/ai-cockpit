## 一、问题

点击或悬停一颗星时，页面同时显示多个节点标签。

老板期望与 Obsidian 一致：

1. 默认缩放级别不显示标签。
2. 鼠标悬停某颗星时，只显示该星标签。
3. 点击某颗星时，只显示该星标签。
4. 拖动某颗星时，只显示被拖动星的标签。
5. 放大到较高倍率时，普通标签再按缩放比例渐显。

---

## 二、Obsidian 标签规则

Obsidian Graph View 的核心公式：

```text
textAlpha = clamp(log2(scale) + 1 - textFadeMultiplier, 0, 1)
```

默认：

```text
textFadeMultiplier = 1
```

因此：

```text
scale = 1 → textAlpha = 0
scale = 2 → textAlpha = 1
```

高亮节点例外：

```text
textAlpha = 1
```

所以悬停或拖拽节点的标签始终显示。

本方实现使用：

```text
viewScale = DEFAULT_RADIUS / camRadius
labelZoomAlpha = clamp(log2(viewScale) + 1 - TEXT_FADE_MULT, 0, 1)
```

## 三、V4 修正

1. 默认视图不显示标签。
2. `activeIdx >= 0` 时只保留当前活动节点标签。
3. 悬停、点击、拖拽统一按活动节点处理。
4. 放大后才让普通标签按 `labelZoomAlpha` 渐显。
5. 非活动标签不再因为 root/core 身份强制显示。
6. 标签透明度直接使用 `labelZoomAlpha`。
7. 标签避让、碰撞检测和底部边界保护保留。
