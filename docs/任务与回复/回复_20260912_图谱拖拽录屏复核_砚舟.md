## 二、交互观察

### 通过

1. 拖拽有效，星图可随鼠标移动改变位置。
2. 滚轮缩放有效，节点会放大和缩小。
3. 缩小到远景后，普通文档标签会收起，仅保留中心节点和三个金色核心库。
4. 中心球体、三个金色知识库节点和连线均可见。
5. 未出现页面白屏、崩溃或 Basic Auth 弹窗。
6. 缩放变化过程中，中心球体和核心节点保持可见。

### 未通过

1. 放大到中景后，多个普通标签会出现并互相压盖。
2. 拖动过程中，标签重叠会随节点位置变化，而不是持续避让。
3. 点击中心节点后的浮层会和旁边标签重叠。
4. 部分标签在星点密集区域形成连续文字块，影响 Obsidian 式清晰网络观感。
5. 当前避让策略只在四个核心标签状态稳健，进入多标签状态后仍失效。

## 五、是否达到预期

**尚未达到。**

当前效果更像：

```text
可拖动、可缩放的 3D 星图
+ 核心态标签干净
+ 中景文档标签拥挤重叠
```

离想要的 Obsidian 式动态知识网络还差一个关键点：

```text
任意缩放级别、任意拖动位置，可见标签都不能互相压盖。
```
